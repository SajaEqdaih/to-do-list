Achievement Planner

A smart, interactive task management dashboard designed to help developers and engineers organize their daily goals with high efficiency.

 Key Features
- Smart Tracking System:** Real-time display of progress percentage and task statistics.
- Modern UI/UX:** Fully supports Dark Mode and features the elegant 'Cairo' font for better readability.
- Interactive Experience:** Celebratory visual effects and motivational toasts upon task completion.
- Data Persistence:** Automatically saves your tasks to LocalStorage so you never lose your progress.
 Technical Stack
-Frontend: HTML5, CSS3 (Modern Flexbox/Grid).
- Logic: Vanilla JavaScript (ES6+).
- Typography: Google Fonts (Cairo).
